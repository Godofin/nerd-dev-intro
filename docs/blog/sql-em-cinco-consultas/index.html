SQL em cinco consultas: do básico ao JOIN

Com cinco comandos você já consegue extrair respostas de um banco de dados. Veja cada um com um exemplo simples de vendas.

Por Equipe Nerd Dev

Neste artigo
  1. 1. SELECT: escolher colunas
  2. 2. WHERE: filtrar linhas
  3. 3. ORDER BY: ordenar
  4. 4. GROUP BY: resumir
  5. 5. JOIN: juntar tabelas
  6. Como praticar

SQL é a linguagem usada para conversar com bancos de dados. Para começar, imagine uma tabela de vendas com as colunas produto, categoria, valor e cliente_id.

1. SELECT: escolher colunas

Mostra só as colunas que você pediu.

2. WHERE: filtrar linhas

Traz apenas as vendas acima de 100.

3. ORDER BY: ordenar

Do maior para o menor valor. Use ASC para o contrário.

4. GROUP BY: resumir

Soma o valor de cada categoria. É a base de muitos relatórios.

5. JOIN: juntar tabelas

Combina a tabela de vendas com a de clientes, ligando os dois pelo identificador.

Como praticar

Crie um banco de teste e invente dados parecidos com os de um negócio que você conhece. Responder perguntas reais, como qual categoria vende mais, é a melhor forma de fixar.
